# Changelog

## 0.1.2

### New
- Add step-by-step sign up with Google and Apple sign in
- Add push notifications that open the right screen when tapped
- Add card top-up through the Paystack checkout
- Add a top-up sheet when the wallet cannot cover a booking
- Add a download button on trip receipts
- Add a Done bar above number and phone keyboards

### Improved
- Match airports by name, code and accents in airport search
- Show a pulsing price until each ride fare arrives
- Keep wallet balances up to date after opening the menu and after a trip
- Tell you when your location could not be found, with Try again
- Say how many seconds to wait when too many requests are sent
- Show friendly messages for missing items instead of server text
- Hide trip PIN, card entry and selfie from the app switcher
- Remember skipped ratings after sign out
- Calm the delivery screens and show the recipient confirmation
- Use a consistent look across menu, place search, profile and history lists
- Update the app icon

### Fixed
- Fix group approvals and group ride history not showing
- Fix scheduled ride cards cutting off the pickup time
- Fix trip chat showing a sent message twice
- Fix adding a stop mid-trip announcing the fare as updated
- Fix the airport list showing a blank page when it fails to load
- Fix the SOS alert counting contacts it did not reach
- Fix permission prompts stacking on top of each other
- Fix US phone numbers being read as another country
- Fix history detail changing its title after loading
- Fix 24 hour times showing a leading zero
